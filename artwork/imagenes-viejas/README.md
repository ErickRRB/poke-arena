# Imágenes anteriores

Abrí [index.html](index.html) para revisar las cartas y sus alternativas. Los originales se copiaron sin modificar. Las ilustraciones que comparten una lámina se muestran por separado en el visor y conservan la lámina completa como archivo de origen.

- `originales/`: escenas anteriores a las renovaciones y el Hiperrayo detallado que se conserva en el juego.
- `variantes/`: alternativas de Hiperrayo y Golem.
- `historicas/`: imágenes reemplazadas o retiradas que se recuperaron del historial del proyecto.
- `catalogo.json`: procedencia, tamaño y checksum de cada archivo.

El dibujo del tronco que reemplazó Rueda Fuego está conservado en `originales/battle-1.webp` y se puede ver como carta individual en el visor.

El archivo se encuentra fuera de `dist` y se puede revisar directamente en el navegador.
