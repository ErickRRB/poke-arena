# Comparación de ataques

Cada recuadro muestra el ataque real de una carta contra un objetivo válido. Al costado se muestra su recurso de proyectil a la escala usada en la arena. La cifra del título es el máximo visible del proyectil en unidades del tablero. Los ataques cuerpo a cuerpo también se revisaron, aunque su cifra corresponde al perfil visual y no a un proyectil lanzado.
